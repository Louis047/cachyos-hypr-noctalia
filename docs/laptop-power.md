# Laptop power behavior

This setup is tuned for a laptop and is not intended to behave identically on a desktop.

## `power-refresh.sh`

Location:

```text
~/.config/hypr/scripts/power-refresh.sh
```

The script is called by Noctalia on startup and on battery state changes:

```toml
[hooks]
battery_charging = "~/.config/hypr/scripts/power-refresh.sh"
battery_discharging = "~/.config/hypr/scripts/power-refresh.sh"
battery_plugged = "~/.config/hypr/scripts/power-refresh.sh"
started = "~/.config/hypr/scripts/power-refresh.sh"
```

## What it does

1. Exits immediately if no `BAT0` or `BAT1` exists.
2. Detects AC by checking every `/sys/class/power_supply/*/online` file.
3. Reads the current monitor information with `hyprctl monitors -j`.
4. Targets `eDP-1`, falling back to the first output matching `^eDP`.
5. Selects a display mode:
   - **AC:** highest available refresh rate at the current resolution.
   - **Battery:** highest mode with a refresh rate rounded to 60 Hz.
6. Updates both:
   - `~/.config/hypr/monitors.lua`
   - `~/.config/hypr/monitors.conf`
7. Runs `hyprctl reload` only if a mode changed.
8. Sets the power profile:
   - **AC:** `performance`
   - **Battery:** `balanced`

## Dependencies

```bash
command -v jq
command -v powerprofilesctl
command -v hyprctl
```

`power-profiles-daemon` provides `powerprofilesctl`.

## Limitations

- The target output is hard-coded to `eDP-1` with an `eDP` fallback. Change `target_output` for a different laptop panel.
- The script assumes the current `width x height` is available in the monitor's mode list.
- It rewrites generated monitor files. `monitors.lua` is also generated by `nwg-displays`, so the two tools can overwrite each other.
- It is intentionally skipped on desktops without a battery.
- The Noctalia hook fires on state transitions; if the display mode does not change, no Hyprland reload is performed.

## Manual test

```bash
~/.config/hypr/scripts/power-refresh.sh
hyprctl monitors
powerprofilesctl get
```

Watch for `jq` errors if `hyprctl` is unavailable outside a running Hyprland session.
