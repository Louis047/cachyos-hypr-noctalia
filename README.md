# cachyos-hypr-noctalia

Personal snapshot of a CachyOS laptop desktop built around **Hyprland** and **Noctalia**, with GTK/Qt theming, Apple-style fonts, and laptop-aware power management.

> This is an archival snapshot, not an installer. Read [`docs/restore.md`](docs/restore.md) before copying anything back.

## Snapshot

| Item | Value |
|---|---|
| Date | 2026-10-31 |
| OS | CachyOS (Arch-based, rolling) |
| Kernel | 7.3.0-4-cachyos |
| Compositor | Hyprland 0.57.0, Lua config |
| Shell/panel | Noctalia 5.4.1 |
| Boot loader | Limine 12.9.4 |
| Hardware | AMD Ryzen 7 5800H; Radeon iGPU + NVIDIA RTX 3060 Mobile; 1920x1080 eDP-1 |
| Terminal | kitty 0.49.2 |
| Login shell | zsh |

The setup is optimized for this laptop. The AC/battery refresh-rate switching in `power-refresh.sh` is intentionally laptop-specific.

## Highlights

- **Hyprland Lua config** split into settings, keybinds, rules, animations, autostart, and monitor files.
- **Noctalia** panel, launcher, lock screen, widgets, plugins, and GUI-managed settings exported into one declarative config.
- **Laptop power automation** through Noctalia battery hooks and `power-refresh.sh`:
  - AC: highest supported refresh rate, `performance` power profile.
  - Battery: 60 Hz, `balanced` power profile.
- **Font stack** based on SF Pro, New York, Apple Color Emoji, and JetBrainsMono Nerd Font.
- **Consistent theming** generated by Noctalia for GTK 3/4, Qt6CT, kitty, btop, zathura, Papirus, and related apps.
- **Documented system tweaks** rather than archiving the whole `/etc` tree.

## Repository layout

```text
home/         Files destined for $HOME, preserving their relative paths
reference/    Raw Noctalia state and dconf export, for reference only
packages/     Native, AUR, and full versioned package snapshots
scripts/      Standalone setup helper scripts
docs/         Restore guide and subsystem notes
```

## Quick restore

1. Review [`docs/restore.md`](docs/restore.md) completely.
2. Install the native and AUR packages from [`packages/`](packages/).
3. Back up your existing `~/.config`, `~/.local`, and `~/.zshrc`.
4. Copy `home/` into your home directory, then replace the `__HOME__` placeholders.
5. Install the New York fonts, apply the documented system snippets, and enable the user services.
6. Validate Noctalia, fonts, and Hyprland before logging back in.

## What is not included

- Proprietary font binaries. The AUR packages and the New York installer are documented instead.
- Wallpapers and avatars. Only their expected paths are recorded in [`docs/assets.md`](docs/assets.md).
- Browser profiles, password-manager data, chat accounts, clipboard history, notification history, and app caches.
- Noctalia's app-managed `state.toml`, plugin caches, and downloaded community-template catalogs.
- System files under `/etc`; those are documented in [`docs/system-notes.md`](docs/system-notes.md).
- The broken Paperweight autostart entry and Paperweight app data.
